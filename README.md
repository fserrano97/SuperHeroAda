# 🦸 Buscador de Superhéroes

Aplicación web para explorar superhéroes y villanos del universo de cómics, con búsqueda, filtros y visualización detallada.

---

## 🌐 Demo

👉 https://super-hero-ada.vercel.app/

---

## 🚀 Funcionalidades

* 🔍 Búsqueda por nombre en tiempo real
* 🦸 Filtro por tipo (Héroe, Villano, Neutral)
* 🏢 Filtro por editorial (Marvel, DC, etc.)
* 🔤 Orden alfabético (A → Z / Z → A)
* 📄 Paginación (20 resultados por página)
* ⏮ Navegación completa:

  * Primera página
  * Anterior
  * Siguiente
  * Última
* 🚫 Botones deshabilitados cuando corresponde
* 📊 Modal con detalle del personaje:

  * Nombre, editorial, altura y peso
  * Afiliaciones
  * Estadísticas con barras de progreso
* 📱 Diseño responsive

---
